# Portfolio

잡코리아 자기소개서 첨부용 포트폴리오. 정적 HTML/CSS/JS, 빌드 없음.

## 구조
```
index.html      뼈대
css/style.css   디자인 (미니멀 라이트, 인쇄 스타일 포함)
js/data.js      ← 내용은 여기만 수정
js/main.js      렌더링
assets/         사진·프로젝트 이미지
```

## 수정
`js/data.js`의 `[대괄호]` 항목을 본인 정보로 교체. 항목 추가/삭제는 배열 요소 추가/삭제.
섹션: 기술 → 연혁 → 개발 → 프로젝트 → 레퍼런스.

## 미리보기
`index.html`을 브라우저로 열기.

## PDF
상단 `PDF` 버튼 → 인쇄 대화상자 → "PDF로 저장". A4 레이아웃 적용됨.

## 배포 (GitHub Pages)
Settings → Pages → Branch 선택 → `/ (root)` → Save.
주소: `https://<아이디>.github.io/<저장소명>/` → 잡코리아 포트폴리오 URL 칸에 입력.

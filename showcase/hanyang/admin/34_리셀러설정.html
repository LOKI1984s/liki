등급 체계
파트너 등급은 총판 · 대리점 2단계이며, 계층 구분 용도예요. 커미션율은 등급에 고정되지 않고 파트너 개별로 리셀러목록 상세에서 직접 설정합니다.
총판
· 본사가 직접 커미션율을 설정해요 (본사 → 총판 지급 라인)
· 하위 대리점을 모집하고, 자기 하위 대리점의 커미션율을 설정할 수 있어요 (총판 페이지에서, 준비중)
· 자기 자신의 커미션율은 수정할 수 없어요 — 본사만 가능
대리점
· 상위 총판 또는 본사가 커미션율을 설정해요 (총판 → 대리점 지급 라인)
· 반드시 상위 총판이 지정되어야 해요
· 하위 파트너를 모집할 수 없어요 (트리 최하단)
지급은 본사가 총판·대리점 각각에게 직접 내려줘요. 총판은 지급 주체가 아니라, 자기 하위 대리점의 커미션율을 정하는 권한만 가져요. 정산은 리셀러정산에서 총판·대리점 건이 각각 별도로 집계됩니다.
